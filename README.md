# Blend In

A web-based party game inspired by The Chameleon. Everyone knows the secret word except the Imposter. Try to blend in, or catch the liar out.

## How to Play

1. Open the game in a browser on your phone.
2. Select the number of players (3–20).
3. Each player takes turns viewing their role:
   - Most players see the secret word.
   - One player is the **Imposter** and must bluff.
4. Ask questions. Find the imposter.

## Play Online

[Play now](https://malachyfernandez.github.io/Chameleon/)

## Run Locally

Simply open `index.html` in any modern web browser. No server required.
